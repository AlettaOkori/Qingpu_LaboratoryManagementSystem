# 实验教学与资源管理

可交互的实验教学与资源管理系统，使用 HTML/CSS/JavaScript 构建。

视觉已按要求恢复：移除后加的绿色主色、字号和等宽卡片覆盖，重新使用原有红橙色操作、侧栏、重点指标卡、登录页和问数页组件。功能增强、数据校验和已确认的冗余入口整理保留。

## 启动与入口

在当前项目根目录运行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory new-demo
```

浏览器访问 [业务入口](http://127.0.0.1:8765/)。始终使用同一个地址/端口；不同来源的浏览器存储不共享。不推荐直接双击 `file://` 文件进行跨页联动操作。

- `index.html`、`login.html`：身份选择入口，不要求真实账号密码。
- `pages/district/`：区级管理。保留旧 `inspections.html` 兼容入口，默认打开安全管理中的检查台账。
- `pages/school/`：学校管理、任课教师和实验员共用页面，操作权限不同。
- `preview.html`：内部页面总览、桌面/平板/手机画布。只从“系统控制”进入，不再是默认首页。

## 数据与计算口径

统计日期：**2026-08-31**。当前台账包含3所学校、9间实验室、15名人员、6个班级、18件设备、12种分校库存、5条实验目录、15条班级计划。学校和人员名称用于展示业务关系。

- 每个资产编号对应一件设备。设备总数含报废档案；在账原值不含已报废设备。
- 初始每校必做应开4次、选做1次；区域必做应开12次。应开按班级计划计次，不按目录条目数。
- 只有“完成登记”更新实开次数，同一计划只计一次。学校/区级/报表/问数共同计算；分母为0显示“不适用”。
- 必做/选做与演示/分组是独立维度。演示/分组列包含必做及选做，不能再与选做列相加。
- 学期筛选作用于教学数据；设备、耗材、安全为当前台账，页面持续说明统计范围。
- 预约“准备确认”不自动扣库存；实际耗材领用另填关联计划的领用单，避免重复扣减。
- 危化品采购到货可形成入库单，但库存流水待第二人复核才入账；到货单不等于已完成库存复核。

## 推荐操作路线

1. **采购入库**：学校“设备与采购→采购申请”查看采购单 `CG-20260831-001`；“系统控制”进入区级；“采购与设备审批→采购申请”审批；切回学校“到货入库”，选择生物实验室。确认后生成2个唯一编号的显微镜档案，可从资产详情追到入库及采购来源。
2. **教学完成**：学校“预约管理”中 `S1-YY1` 已准备。用学校管理员或物理教师张明华填写人数与总结后确认完成。学校必做开出率变为25.0%（1/4），区级为8.3%（1/12），刷新保留。新预约可申请、审批、实验员准备并校验冲突。
3. **安全闭环**：学校“安全管理”找到锁具隐患；“整改附件→生成关联业务说明→保存附件”；“提交整改”选择刚保存的文件；区级“安全管理”复查，可通过或退回；详情展示整改说明、附件和轨迹。
4. **库存与异常**：以学校管理员复核实验员提交的乙醇领用单。库存从12瓶变11瓶，重复复核不可执行。自行提交的危化品业务须切换另一名责任人复核。
5. **导入/导出**：“设备与采购→模板导入”下载CSV模板或填入内容；负数数量校验失败；正确内容预览通过后确认入库。导出遵循当前筛选和勾选范围。统计报告为可在浏览器查看/打印的HTML文件，不伪装PDF。

记录完成时，不会重复提供“确认完成/审批”等不符合状态的操作。可以新增下一条业务，或在系统控制中先备份、再输入“恢复数据”重置。重置不能撤销。

## 角色、数据与边界

- 区级管理员：跨校查看，采购/设备审批、安全复查、基础数据与平台设置。
- 学校管理员：本校档案、预约审批、验收、整改、上报；也可执行日常资源业务。
- 任课教师：自己的教学计划、预约、完成登记和资料，提交耗材领用/报修。
- 实验员：设备与库存业务、实验准备、检查/整改，不代替教师确认实验完成。
- 权限由页面角色规则控制。同源 localStorage 保存业务，sessionStorage 保存当前窗口身份；不向参考平台或其他服务发送业务数据。真实并发、服务端鉴权、审计防篡改、灾备需后端实现。
- 系统控制支持JSON备份与确认重置。暂无备份文件恢复UI；JSON保留完整原始记录，可交给开发人员恢复。
- 单个附件最大512KB，保存于浏览器，配额不足时明确报错且不提示成功。支持PDF、PNG、JPG、TXT、CSV、DOCX、XLSX原文件保存与下载；只有文本内嵌预览。不上传真实敏感资料。
- 模板导入只支持CSV，单次1—30行、最多100件；不支持直接导入XLSX。采购为整单到货，不支持部分收货或完整商城流程。
- 资产标签为可打印的**编号文本卡**，不是条码编码。支持输入编号和扫码枪键盘输入；未做摄像头、标签打印机和专用扫描硬件适配。
- 工作台提醒与周报按钮按页面设置显示；不发送邮件、短信或自动后台任务。问数不宣称合规或安全评级。
