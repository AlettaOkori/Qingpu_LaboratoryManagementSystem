## 3. 入库单

截图：`4d8214d003d8411a8d71b064438863fd.png`。

| 参考字段 | 当前表单与保存字段 | 调整 |
| --- | --- | --- |
| 入库单号 | `id` | 保存时生成，表单只读提示，详情显示实际单号 |
| 供应商、购置日期、登记日期 | `supplier`、`purchaseDate`、`date` | 字段名称对齐；购置日期不能晚于登记日期 |
| 分类编号 | `items[].classificationCode` | 新增，传递至资产／耗材档案；不编造分类代码 |
| 名称、规格、单位、数量、单价 | `items[].name/model/unit/qty/price` | 保留，逐行填写 |
| 总价 | 数量×单价 | 逐行及整单实时计算，详情再次按保存值计算 |
| 存放位置（房间） | `items[].labId/location` | 每行可单独设置；留空可使用单据默认位置 |
| 经手人 | `operator` | 自动取当前操作人，不允许任意冒填 |
| 备注 | `note` | 新增并在详情保留 |

审批采购单入库时只补分类编号（原来未填时）及位置，不能篡改已审批的名称、数量、价格。仍使用整单收货流程，不把截图中未确认语义的“完成／保存”照搬为可绕过审批的按钮。

耗材合并库存同时核对学校、名称、规格、单位、分类编号、管理类别和存放位置（房间），不跨房间合并。危化品仍在第二人复核后记账。

CSV模板扩为9列：原六列＋分类编号、实验室编号、存放位置（房间）。仍兼容原六列模板；位置空白使用单据默认位置，跨校实验室编号会拦截。

| 参考字段 | 当前表单与保存字段 | 调整 |
| --- | --- | --- |

| 章节、实验名称、实验器材 | `catalog.chapter/name/equipment` | 随所选实验自动展示 |

当前仍按“班级×实验×学期”逐项编制，避免改动统计分母；没有新增截图中的独立计划组管理器或整教材批量编排器。计划名称为输入项，不声称复制了参考站点的计划名称下拉及管理流程。目录已有新增入口，自定义实验由区级维护统一目录后编制。

教材、章节、器材是关联目录的当前信息，不另造一份可与目录冲突的文本。周次以学期开始日期所在周为第1周，周一为一周开始。

## 5. 实验预约单

截图：`71961c674b9544e398356cc05375317e.png`。

| 参考字段 | 当前表单与保存字段 | 调整 |
| --- | --- | --- |
| 预约时间 | `bookedAt` | 新增，提交时记录实际时间 |
| 实验内容：章节、实验名称、实验器材 | 每行 `planId` 关联计划及目录 | 自动展示，支持添加多条班级／实验安排 |
| 补充实验仪器：分类编号、名称、规格、数量 | `resources[].ref/qty` 关联资产或耗材 | 增加分类编号及规格展示，按需填写数量 |
| 实验类型 | 来自关联计划 `mode` | 自动带入，避免预约与计划类型不一致 |
| 班级、时间、分组数 | 每行计划的班级及 `date/start/end/groups` | 多行安排，每行独立校验 |
| 备注 | `note` | 最多100字 |
| 任课教师 | `teacherId` | 由任课计划带入 |
| 预约人 | `applicant/applicantId` | 由当前账号带入 |
| 实验管理员 | `managerId` | 新增，默认带入实验室管理员；选择同校启用的管理员／实验员 |

与截图交互区别：当前将“实验内容”和“班级安排”合为每行一个班级实验计划，不做两个列表的隐式笛卡尔组合，也不允许对不存在的班级计划预约。

## 数据兼容与验收

- 存储键及数据版本结构保持不变，没有重置用户已有台账、附件或处理状态。
